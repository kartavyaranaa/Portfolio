# Kartavya Rana — Portfolio

Static portfolio built with HTML, CSS and JavaScript. No build step required.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the contents of this folder to a GitHub repository, or deploy the folder directly to Vercel/Netlify.

## Notes
- The live clock is implemented in `script.js` with `new Date()` and `setInterval(..., 1000)`.
- Project links point to Kartavya Rana's current GitHub repositories.
